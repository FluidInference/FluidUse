# FrontDoorDemo — Chatbot Front Door

A support chatbot's incoming traffic (1,000 synthetic messages: `Traffic1000.swift`, generated by
`/Users/hanweng/Documents/vela2/frontdoor/gen1000.py`, seeded) screened and sorted on this Mac by
Vela-2.0-0.3B (Core ML). Each message gets two calls:

1. **guard** — `attack` + `p_harm` (trained wording; ≈92-token schema → 128-token Neural Engine bucket).
   jailbreak ≥ 0.8 → blocked (jailbreak); else unsafe ≥ 0.8 → blocked (harmful).
2. **route** — only if not blocked: `topic` (billing / technical / account / shipping / general) + `pii` spans (GPU).
   Personal info is shown redacted as `[LABEL]` chips.

```
swift run -c release FrontDoorDemo [--model <dir>]   # or VELA_DIR=<dir>; default /Users/hanweng/Documents/vela2/release03
swift run -c release FrontDoorDemo --demo            # start the run automatically
swift run -c release FrontDoorDemo --selftest        # no window: all 1,000 + model-vs-expected confusion
```

The model loop is strictly sequential and runs off the main actor as fast as the model allows; the traffic arrives as a burst
plus a 250 msg/s stream so the queue never starves; the UI applies results at most every 50 ms and each lane renders only its
latest 20 rows. The run stops after the last message with a compact summary (Replay restarts it). Click a row for the original
text (PII highlighted), attack / harm / topic probabilities and both timings.
